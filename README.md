# LXBE EPK — Final Website

Self-contained English electronic press kit for LXBE.

## Open locally
Open `index.html` in a modern browser.

## Publish
Upload the complete `LXBE-EPK-Final` folder to a static host such as Netlify, Cloudflare Pages, GitHub Pages, or any standard web server.

All logos and photography used by the page are stored inside `assets/`. The project does not depend on the former Manus website.

The 2026 performance list includes Chica Club — Barcelona, Spain, placed after Cantina 15.

## Browser icon
The official LXBE logo is included as the favicon for tabs, bookmarks, mobile shortcuts and compatible browser interfaces.

## Interactive map
The International section includes a self-contained SVG world map. Countries where LXBE has performed are highlighted in orange and link to the matching performance year.
